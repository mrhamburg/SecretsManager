# SecretsManager Documentation

This is the documentation site for SecretsManager, built with [Docusaurus 3](https://docusaurus.io/).

## Local Development

```bash
npm install
npm start
```

This starts a local development server at `http://localhost:3000` with hot-reload.

## Build

```bash
npm run build
```

The static site is generated in the `build/` directory.

## Docker

```bash
docker-compose up --build
```

Serves the documentation at `http://localhost:8080`.
